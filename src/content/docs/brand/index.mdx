The logos, the symbols, the avatars and the illustrations of the Maggioli Group and of its
products are published as `@maggioli-design-system/identity`, one artwork per file, each in
SVG, PDF, PNG and WebP. The pages of this section show every artwork of the package with all
its files to download; [Identity package](identity-package/) tells how to install it and use
its files in a project.

## Formats

| Format | Size                   | For                                |
| ------ | ---------------------- | ---------------------------------- |
| SVG    | Vector                 | Web pages and apps                 |
| PDF    | Vector                 | Print and documents                |
| PNG    | 256, 512, 1024 px wide | Email, presentations, social media |
| WebP   | 256, 512, 1024 px wide | Web pages that need a raster image |

SVG is sharp at any size and the smallest file: use it wherever it is accepted, and a PNG where
it is not. Most artworks come in color and, for one-color uses, in black and in white. The
cards show each artwork on the background it is drawn for: the white ones on a dark background.

## Names and descriptions

The names of the brands and of the products on these pages come from the package, as the
artworks write them. The package has no descriptions yet, nor the rules for using each brand,
such as its clear space, its minimum size and its backgrounds: the descriptions are written by
this site from the kind of artwork, as defaults.
