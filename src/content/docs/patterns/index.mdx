## What a pattern is

A component solves one part of a screen; people come to a product to get something done. A
pattern is the solution to a task that the products of Maggioli Group meet again and again:
telling the person what happened after an action, asking before one that cannot be taken back,
showing a part of the page with nothing in it, searching a long list. It puts Magma components
and [building blocks](../blocks/) together, and takes the decisions the components cannot take
on their own: where a message goes, what the person can do while waiting, what follows an
error.

The patterns ship with Magma, in the package `@maggioli-design-system/magma`. Each page here is
generated from the file of its pattern, the same file an AI agent reads, and it is written in
English.

## Reading a pattern

A pattern starts from a few variables of the situation: whether the action can be undone, how
many items it acts on, where the person is when it ends. Each combination of their values is a
**case**, which names the components to use and how to use them. The stage at the top of the
page runs the cases one at a time, with a line on what to try: pick one there, or click its id
in the table of the cases. Then come:

- **Always true**: the rules that hold in every case and in every product.
- **Open choices**: what a product may decide for itself, with the default that holds until it
  does.
- **Situations**: real situations, each with the case it falls in. They are the quickest way to
  find yours.
- **Decisions**: when each rule was decided and why, with the link to the discussion.

A **candidate** is a need Magma knows and has not defined yet: its page holds the need only.
Until the pattern is defined, choose what fits the product, write down why, and propose it to
the Magma team.

## With an AI agent

An agent does not read these pages: it asks the Magma MCP server for the pattern, `get_pattern`,
with the values of the variables it knows, and gets back the one case to follow and its rules.
The page of each pattern has a prompt to give it. How to set the agent up is in
[Agentic development](../ai/).

## The layer of a product

A product can narrow a pattern without copying it. A file in its own repository,
`magma/patterns/<id>.md`, fixes the open choices and adds the situations of the product; the
rules that are always true stay as they are. `get_pattern` applies the layer of the project it
runs in.
