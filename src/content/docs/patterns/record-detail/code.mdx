The plain HTML version is the one running in the preview of the [overview](../): it opens from the numbers of the
[list with filters](../../list-with-filters/), and its link goes back to it. In all three,
`fetchRecord` and `runAction` stand in for the back end and work on demo data: replace them with
the calls to your API. The React component receives the id of the record from its parent; the
Angular component reads it from its route, `/requests/:id`.
