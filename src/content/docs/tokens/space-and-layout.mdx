## Spacing

Magma's Tailwind theme sets `--spacing` to `0.0025rem`, so a numeric step reads as a
size: `p-100` is `100 x 0.0025rem`, a quarter rem (4px), `gap-400` is 1rem. Next to the
numbers come the named steps, and the text measures in `ch`: the widths that keep a line
readable (`max-w-text` for running text).

## Sizing scale

The numeric steps the spacing, container, border and radius tokens are made of. They have
no custom property of their own: in Tailwind each one is a step of every spacing utility.

<TokenTable tokens="size" />

## Containers

Widths for content blocks and container queries. The width utilities read them by name:
`max-w-xs` is `--container-xs`, and so are `w-xs`, `min-w-xs` and `basis-xs`. The logical
sizes read the spacing of the same name instead: for the container write
`max-inline-(--container-xs)`. The container query variants (`@md:`) read the containers.

## Breakpoints
