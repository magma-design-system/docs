## Corner radius

Magma draws its corners as squircles by default, and a squircle cuts a much smaller
corner than a round one at the same radius. So the corner shape and the radius scale move
together, as one axis: `data-corner-shape="round"` or `"squircle"`, on `<html>` or on any
element for its subtree.

In your own CSS take radii from the Magma scale, which follows the axis:

```css
.card {
  border-radius: var(--magma-radius-lg);
  corner-shape: var(--magma-corner-shape);
}
```

<TokenTable tokens="magma.radius" />

Tailwind's `rounded-*` classes read the primitives below, which stay the same under every
shape: `rounded-md` is always the round 12px. For the axis write
`rounded-(--magma-radius-md)`. The `squircle-*` steps are the ones tuned for the squircle.

## Shadows

In light mode the surfaces above the page are close to it, so a raised element needs a
shadow to stand off: `mds-card` uses `shadow-md-sharp`, `mds-modal` `shadow-2xl`. The ring
shadows are drawn with the darkest neutral and change in dark mode.

<TokenTable tokens="shadow" />

## Elevation and depth

Two elevation shadows whose offsets, blur and opacity are multiplied by `--depth`. They
come from `styles/dist/css/theme.css`, which the documented setup does not import, and no
component reads them yet: they exist only in a project that imports that file. There,
`data-theme-depth="flat"` on `<html>` sets the depth to 0 and takes the shadows away.

## Global decisions

The scrim under modals, the opacity of disabled elements and the focus outline. Override
them only inside the `overrides` cascade layer:

```css
@layer overrides {
  :root {
    --magma-disabled-opacity: 0.35;
  }
}
```
