Magma names an icon by its slug: the set it comes from, then its name. `mds-icon` and every
component with an `icon` prop take a slug and load the SVG file of that name;
[iconsauce](iconsauce/) writes the files, or an icon font with the same names.

How to use the icons, and how they get into a product:

<PageCards
  pages={[
    { slug: 'icons/using-icons', icon: 'mi/outline/interests' },
    { slug: 'icons/iconsauce', icon: 'mi/outline/terminal' },
  ]}
/>

## Packages

Three sets work this way, each from a package of its own:

<IconSets />

The page of each set lists all its icons, one category at a time, and its search looks
through the whole set, also by the tags the set gives its icons. A click on an icon copies
its slug, or the markup that uses it.

Apps that still use the legacy icons package find its names, each with the slug that
replaces it, in [Icons package (legacy)](icons-package/).
