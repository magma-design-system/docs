import LegacyIcons from '../../../components/LegacyIcons.astro';

Every name of `@maggioli-design-system/icons`, the icon font package, with the iconsauce slug
that draws the same icon below it. A click copies the name in the form the app uses: the class
of the icon font, its markup, the member of the TypeScript enum or the name of the SVG file.
[From the icons package](../iconsauce/#from-the-icons-package) tells how to move to iconsauce.
