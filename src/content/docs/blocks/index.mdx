## What a building block is

A page is made of sections, and many of them come back from one product to the next. A building
block is one of those sections, made of Magma components and always laid out the same way: the
shell of the application around every page, the header of a page with its title and its
actions, a list of items, the labels and the values of an item.

A building block is about space: which regions it has, when each one shows, in which order they
come and how they adapt to the width. What happens over time - a message, a wait, an error -
belongs to the [patterns](../patterns/), which use the blocks.

The building blocks ship with Magma, in the package `@maggioli-design-system/magma`. Each page
here is generated from the file of its block, the same file an AI agent reads, and it is written
in English.

## Reading a block

A block starts from a few variables of the page: whether it sits at the top of the application
or inside it, whether it shows one item or a set of them. Instead of cases it has **regions**, in
the order of the page, each saying when it shows; **Layout** says how they stand at each width.
**Situations** are real pages, which the stage at the top of the page runs one at a time.
**Always true** and **Decisions** work as for a pattern.

## Where they come from

The building blocks are not designed in advance: they come out of the patterns. A section of a
page becomes a block when it comes back in two or three patterns, so that it is written once and
every page that needs it builds it the same way.

## The layer of a product

A product can narrow a block as it narrows a pattern, in a file of its own repository,
`magma/patterns/<id>.md`: it fixes the open choices of the block, such as the logo of the
product in the application shell or the items of a list shown as cards, and adds the pages of
the product as situations, each with the values of the variables of the block. The regions and
the rules that are always true stay as they are, and `get_pattern` applies the layer of the
project it runs in:
