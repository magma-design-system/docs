The images on this page present Magma outside this site: in a chat, in a post, in a slide, in
the profile of an account, in the form of a directory that lists design systems. Each card tells
what an image is for and how large it is. **Download** saves the file; the arrow next to it
opens the file again with its full URL, to copy where a form asks for the address of an image
instead of the file. The URLs stay the same when an image is updated.

## Link previews

What chats and social networks show when someone shares a link. The link preview is the image
of every page of this site: share any page and it shows. The GitHub one is uploaded by hand in
the settings of the repository, since GitHub does not read it from a URL.

<MediaKit group="previews" />

## Posts

Images to publish in a post, in the shapes feeds show best: the square one fits anywhere, the
portrait one takes more room on a phone, the story fills its screen, the landscape one suits
feeds of wide images.

<MediaKit group="posts" />

## Profile pictures

The avatar of Magma, the mark on white, at the sizes profiles ask for. It is drawn from the
avatar of the identity package every time the site is built, and the mark stays inside the
circle most profiles crop the picture to. The same avatar, in SVG, PDF, PNG and WebP, is among
the [avatars](../../brand/avatars/#avatar-magma) of the Brand assets.

<MediaKit group="avatars" />
