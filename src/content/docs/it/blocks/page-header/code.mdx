La versione in HTML è quella in funzione nell'anteprima della [panoramica](../): le intestazioni
di due pagine, un record con tutte le parti e una lista con la sua azione principale. In React e
in Angular il building block è un componente che riceve le sue parti, con le azioni come
contenuto; l'esempio in fondo a ogni file costruisce le stesse due intestazioni.

Gli esempi sono in inglese, come il codice: i testi dell'interfaccia vanno tradotti nella lingua
del prodotto.
