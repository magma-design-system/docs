La versione in HTML è quella in funzione nell'anteprima della [panoramica](../): una schermata,
gli utenti di un back office, con un'azione per ogni caso. Il suo pannello Try the cases, che fa
fallire il server o scadere la sessione, fa parte della demo, non della schermata. `server` fa le
veci del back end e lavora su dati di esempio: sostituiscilo con le chiamate alla tua API. Le
versioni React e Angular non sono ancora scritte.

Gli esempi sono in inglese, come il codice: i testi dell'interfaccia vanno tradotti nella lingua
del prodotto.
