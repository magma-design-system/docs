Magma contiene un server MCP dentro `@maggioli-design-system/magma`, il comando `magma-mcp`.
Il client dell'agente lo avvia nel progetto, e risponde dalla versione installata lì: i
componenti e la loro API, i ruoli e i token, le classi del tema Tailwind di Magma, le icone
che esistono, le sezioni delle guide, e il lint su un frammento di codice prima che sia
scritto. Legge soltanto: nessuno strumento modifica un file.

Una domanda al server costa una risposta breve, dove la stessa domanda alle guide costa un
file da leggere: i valori di una prop invece della guida del componente, il ruolo per un
"testo secondario" invece della guida dei colori. E quello che il server risponde è
verificato sul pacchetto, non ricordato.

## Configurarlo

Non c'è niente da pubblicare o da installare oltre a Magma: il server gira da
`node_modules`, sul tuo computer, attraverso l'input e l'output standard del client. Non è un
servizio remoto, e non è uno dei connettori di un'app di chat.

**Claude Code**: registra il [plugin di Magma](../claude-code/), che avvia il server e
aggiunge le skill. Con il plugin, non scrivere anche la voce qui sotto, o il server parte due
volte.

**Claude Code senza il plugin**: `.mcp.json` alla radice del progetto, nel repository perché
lo abbia tutto il team; Claude Code chiede una volta prima di avviare un server del progetto.

```json title=".mcp.json"
{
  "mcpServers": {
    "magma": { "command": "npx", "args": ["--no", "magma-mcp"] }
  }
}
```

**VS Code con GitHub Copilot**: `.vscode/mcp.json`.

```json title=".vscode/mcp.json"
{
  "servers": {
    "magma": { "type": "stdio", "command": "npx", "args": ["--no", "magma-mcp"] }
  }
}
```

**Cursor**: `.cursor/mcp.json`, con la stessa voce di Claude Code sotto `mcpServers`.

Unisci la voce al file quando esiste già, non sostituirlo mai. Tieni `--no`: fa eseguire a
`npx` il comando installato e lo ferma quando non c'è, per esempio in un clone appena fatto
prima di `npm install`, invece di scaricare quello che il registro npm ha con quel nome.
Quando il client avvia i server fuori dalla radice del progetto, aggiungi
`"--root", "<cartella>"` agli `args`.

risparmia; gli argomenti che finiscono con `?` sono facoltativi:

installati nel progetto: configura prima il lint.

## Quando l'agente li chiama

La guida `agents/mcp.md` dice all'agente quando usare ogni strumento:

- prima di scrivere un componente, `find_component`, poi `get_component` e `get_usage`;
- prima di un colore, una spaziatura o una classe, `list_tokens`, `suggest_role` o
  `explain_class`;
- prima di un'icona, `find_icon`;
- dopo aver scritto, `check_markup`, poi il lint del progetto;
- dopo l'installazione, o quando qualcosa non si vede, `check_setup`;
- quando nessuno strumento risponde a ciò che serve, o una risposta dice che Magma non ha
  nulla (`gap`), te lo dice, va avanti e alla fine propone una issue su Magma per ogni
  risposta mancante: la apre solo se sei d'accordo.
