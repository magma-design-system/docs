Magma chiama un'icona con il suo slug: il set da cui viene, poi il suo nome. `mds-icon` e ogni
componente con una prop `icon` ricevono uno slug e caricano il file SVG con quel nome;
[iconsauce](iconsauce/) scrive i file, oppure un font di icone con gli stessi nomi. Tre set
funzionano così:

<IconSets />

La pagina di ogni set elenca tutte le sue icone, una categoria alla volta, e la sua ricerca
guarda in tutto il set, anche nei tag che il set dà alle sue icone. Un clic su un'icona copia
il suo slug, oppure il markup che la usa.

Da quale set prendere un'icona, quando usarla e come sceglierla:
[Usare le icone](using-icons/).

Le app che usano ancora il pacchetto icons legacy trovano i suoi nomi, ognuno con lo slug che
lo sostituisce, in [Pacchetto icons (legacy)](icons-package/).
