Ogni nome di `@maggioli-design-system/icons`, il pacchetto del font di icone, con sotto lo slug
iconsauce che disegna la stessa icona. Un clic copia il nome nella forma che usa l'app: la
classe del font di icone, il suo markup, il membro dell'enum TypeScript o il nome del file
SVG. [Dal pacchetto icons](../iconsauce/#dal-pacchetto-icons) spiega come passare a iconsauce.
